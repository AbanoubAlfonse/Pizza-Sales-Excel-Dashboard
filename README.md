# Pizza Sales Performance Dashboard

## 📊 Project Overview
This project analyzes pizza sales data using Excel.

The goal is to understand:
- Sales trends
- Peak hours
- Traffic impact
- Delivery performance
- Best-selling pizzas

## 🛠 Tools Used
- Excel
- Power Query (Data Cleaning)
- Pivot Tables (Data Analysis)
- Dashboard & Slicers (Data Visualization)

## 📈 Key Insights
- Most orders happen during peak hours
- High traffic increases delivery time
- Some pizza types sell more than others
